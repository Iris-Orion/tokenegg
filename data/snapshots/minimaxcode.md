Token Plan 与积分
查看 MiniMax Code 的用量、订阅状态和积分余额。
在设置的用量页面中，你可以查看当前 Token Plan、积分余额、使用额度和发票入口。 ​
每日签到
打开 MiniMax Code 完成每日签到即可领取积分奖励。
每日签到可领取 400 积分
连续签到第 4 天、第 7 天，单日奖励加码至 1000 积分
完成一周签到，累计可领取 4000 积分
签到积分可累计使用，自到账之日起 30 天内有效
积分适用于 MiniMax Code 的各类任务场景，从办公、Coding、深度调研和专业数据库调用，到 PPT、文档、图片、音频及视频等多模态创作，都可以直接使用。 ​
