# Token Plan 与积分

查看 MiniMax Code 的用量、订阅状态和积分余额。

在设置的用量页面中，你可以查看当前 Token Plan、积分余额、使用额度和发票入口。![Image 3: 用量与模型页面](https://mintcdn.com/agent-cn/BK6oKQ5dsiqXZ-jT/images/code/usage-model.png?fit=max&auto=format&n=BK6oKQ5dsiqXZ-jT&q=85&s=f318eee878ccb075447dbec34683f7e3)
## [​](https://agent.minimaxi.com/docs/code/account/usage#%E6%AF%8F%E6%97%A5%E7%AD%BE%E5%88%B0)

每日签到

打开 MiniMax Code 完成每日签到即可领取积分奖励。
*   每日签到可领取 **400 积分**
*   连续签到第 4 天、第 7 天，单日奖励加码至 **1000 积分**
*   完成一周签到，累计可领取 **4000 积分**
*   签到积分可累计使用，自到账之日起 30 天内有效

积分适用于 MiniMax Code 的各类任务场景，从办公、Coding、深度调研和专业数据库调用，到 PPT、文档、图片、音频及视频等多模态创作，都可以直接使用。
## [​](https://agent.minimaxi.com/docs/code/account/usage#%E5%8F%AF%E4%BB%A5%E6%9F%A5%E7%9C%8B%E4%BB%80%E4%B9%88)

可以查看什么

*   当前订阅状态
*   Token Plan 有效期
*   MiniMax 积分余额
*   用量额度
*   订阅、充值、发票和签到入口

具体计费和额度规则以产品内展示为准。
