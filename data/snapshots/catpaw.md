# 产品介绍

### 什么是 CatPaw

CatPaw 是一款 AI 协作工作台。它不只是一个聊天窗口——你说出需求，AI 帮你规划、执行、交付，从一句话到一份可用的成果。CatPaw 支持 macOS、Windows、Mobile（安卓/iOS/iPad）和 Cloud 模式，覆盖桌面办公、移动协作和云端运行等多种场景。

![Image 2: CatPaw 主界面截图](https://s3plus.meituan.net/catpaw-external-resources/catpaw-docs/desktop-1/desktop-1.png)

### 核心亮点

#### PC + Mobile + Cloud，随时随地与 AI 协作

CatPaw 支持 macOS、Windows、iOS、Android 四端实时同步。

电脑上发起的任务，手机上随时查看进度；手机上用语音快速记录的想法，回到电脑继续展开。同一个工作台，在不同设备上无缝延续。

Cloud 模式让任务完全运行在云端——电脑关机也没关系，布置完任务，剩下的交给 AI。关机不中断、云端持续运行、不占本地资源。

CatPaw 还具备持久化记忆能力，AI 会跨会话记住你的偏好、习惯和工作上下文，用得越久，协作越顺。

#### 对话即交付，多 Agent 自主协同

CatPaw 中的 AI 具备完整的任务执行能力——可以访问你的文件系统、运行终端命令、操控浏览器、生成多格式产物文件。只需明确最终目标，Agent 便会自主规划步骤并在授权范围内深度执行：读取文件、操作浏览器、运行终端命令，直接交付 Excel、可视化报告或代码等可用成果。

面对跨领域的复杂任务，系统动态进行任务拆解，调度多个具备专属工具的 Agent 并发处理，各 Agent 在独立环境中互不干扰，进度实时可见，结果自动汇总。

#### 专家与技能，丰富能力即装即用

CatPaw 支持 AI 专家，每位专家集成多项技能与子代理，高效完成特定领域的复杂任务。从专家广场一键安装即可使用，也可通过对话将自己的工作方式快速封装为专属专家，团队共享复用。

平台内置丰富的技能库，开箱即用。内嵌浏览器还支持操作过程一键录制，将日常高频流程自动生成专属技能，让个人与团队经验沉淀为可复用的数字化资产。

### 更多特性

除了以上核心亮点，CatPaw 还提供了丰富的辅助能力来支撑日常使用。

**多面板协作布局** — 侧边栏、对话区、预览面板、文件面板、终端面板五大区域可自由调整，适应不同工作场景。

**沙箱安全机制** — 双级沙箱模式（工作区写入/完全访问）为 AI 操作提供灵活的安全边界，高风险操作需用户确认。

**MCP 扩展** — 支持通过 MCP（Model Context Protocol）协议接入外部工具和服务，进一步拓展 AI 的能力边界。

**自定义命令** — 将常用的提示词模板封装为斜杠命令，输入 / 即可快速调用，提升重复操作效率。

**桌面宠物** — 桌面陪伴宠物，任务运行时陪你等待，有新消息时举牌提醒。支持拖拽、缩放和自定义宠物包导入。
